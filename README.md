# Gorzdrav Bot

Телеграм-бот с мини-приложением, который следит за свободными номерками
в поликлиниках Санкт-Петербурга и пишет, когда появляется подходящий.

Настройка целиком живёт в мини-приложении: выбор района, поликлиники,
специальности и врача, фильтр по времени приёма и просмотр свободных
номерков. Бот только присылает уведомления.

## Фильтр по времени

У каждой подписки своё окно времени. Номерки вне окна игнорируются
полностью — уведомления по ним не приходят.

Например, при фильтре «с 17:00» и номерках на 12:00, 15:00 и 18:00
бот напишет только про 18:00.

Окно через полночь (22:00–06:00) тоже поддерживается.

## Запись по направлению

Отдельная вкладка: номер направления и фамилия → список врачей со свободными
номерками → выбор слота → подтверждение → запись создаётся в горздраве.
Созданные записи видны списком, каждую можно отменить.

Направление можно поставить под наблюдение с тем же фильтром по времени —
бот сообщит о новых подходящих номерках.

Горздрав **не проверяет фамилию** и отдаёт карточку пациента по одному лишь
номеру направления. Приложение сверяет фамилию само и отклоняет запрос при
несовпадении. Номер направления и фамилия хранятся в базе и никогда не
попадают в логи.

Создание записи (`POST /appointment/create`) повторяет запрос страницы
`gorzdrav.spb.ru/service-referral-schedule` вплоть до набора полей. Ответ
`errorCode 616` означает отказ медицинской информационной системы самой
поликлиники — со стороны приложения он неотличим от временного сбоя МИС.

## Запуск

```bash
cp .env.example .env   # и заполнить BOT_TOKEN + WEBAPP_URL
docker compose up -d --build
```

Если где-то ещё запущена прошлая версия бота с тем же токеном — остановите её.
Telegram отдаёт апдейты только одному поллеру, иначе два процесса будут
перехватывать сообщения друг у друга.

`WEBAPP_URL` — публичный **HTTPS**-адрес, по которому доступен сервис.
Телеграм не открывает мини-приложения по HTTP. Тот же адрес нужно указать
в @BotFather: `/setmenubutton` или `/newapp`.

### Локально, без телеграма

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
SKIP_AUTH=true BOT_TOKEN=any DATABASE_PATH=./data/subscriptions.db python run.py
```

С `SKIP_AUTH=true` подпись initData не проверяется, и мини-приложение
открывается прямо в браузере на `http://localhost:3003`. В продакшене
переменная должна быть `false`.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `BOT_TOKEN` | — | Токен бота от @BotFather |
| `WEBAPP_URL` | — | HTTPS-адрес мини-приложения |
| `HOST` / `PORT` | `0.0.0.0` / `3003` | Адрес веб-сервера |
| `DATABASE_PATH` | `/app/data/subscriptions.db` | Файл SQLite |
| `CHECK_INTERVAL` | `300` | Пауза между проверками расписания, секунды |
| `REQUEST_DELAY` | `0.4` | Пауза между запросами к горздраву, секунды |
| `MAX_SLOTS_IN_MESSAGE` | `30` | Сколько номерков перечислять в уведомлении |
| `SKIP_AUTH` | `false` | Отключить проверку подписи Telegram |

## Структура

```
run.py                    точка входа: FastAPI + поллинг бота + мониторинг
app/
  bot.py                  /start с кнопкой мини-приложения и уведомления
  config.py               настройки из .env
  database.py             SQLite и миграция со старой схемы
  gorzdrav.py             клиент API gorzdrav.spb.ru
  api/
    auth.py               проверка подписи Telegram initData
    routes.py             REST для мини-приложения
    schemas.py            валидация запросов
  services/
    slots.py              сбор номерков и фильтр по времени
    checker.py            фоновый цикл проверки подписок
  static/                 мини-приложение
```

## API

Все запросы, кроме `/api/health`, требуют заголовок `X-Telegram-Init-Data`.

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/districts` | Районы города |
| `GET` | `/api/districts/{id}/lpus` | Поликлиники района |
| `GET` | `/api/lpus/{id}/specialities` | Специальности поликлиники |
| `GET` | `/api/lpus/{id}/specialities/{id}/doctors` | Врачи специальности |
| `GET` | `/api/subscriptions` | Список подписок |
| `POST` | `/api/subscriptions` | Создать подписку |
| `PATCH` | `/api/subscriptions/{id}` | Изменить окно времени или паузу |
| `DELETE` | `/api/subscriptions/{id}` | Удалить подписку |
| `DELETE` | `/api/subscriptions` | Удалить все подписки |
| `GET` | `/api/subscriptions/{id}/slots` | Свободные номерки по подписке |
| `POST` | `/api/slots/preview` | Номерки до создания подписки |
| `GET`/`POST`/`DELETE` | `/api/favorites` | Избранные поликлиники |
| `POST` | `/api/referral/lookup` | Направление по номеру и фамилии |
| `GET` | `/api/referrals` | Направления под наблюдением |
| `POST` | `/api/referrals` | Поставить направление под наблюдение |
| `PATCH`/`DELETE` | `/api/referrals/{id}` | Окно времени, пауза, снятие |
| `GET` | `/api/referrals/{id}/slots` | Номерки по направлению |
| `POST` | `/api/referrals/book` | Записаться на выбранный номерок |
| `GET` | `/api/bookings` | Мои записи |
| `POST` | `/api/bookings/{id}/cancel` | Отменить запись |

## Обновление с прошлой версии

Схема базы мигрирует автоматически при первом запуске: к таблице
`subscriptions` добавляются колонки фильтра, а название поликлиники
подтягивается из избранного. Существующие подписки сохраняются и
получают окно «любое время».

Записаться на приём бот не умеет — только следит за расписанием.
Запись остаётся на [gorzdrav.spb.ru](https://gorzdrav.spb.ru/service-free-schedule).

API горздрава неофициальный, [описание эндпоинтов](https://github.com/egorantonov/gorzdrav/wiki/SPB-Gorzdrav-API-Documentation).
